# SME workspace rules
- SME surfaces enable human Gate C / gold-set / melanoma pilot review — never bulk-approve, invent PMIDs, silent KEYNOTE rematch, or enable Trial Intelligence in production.
- Work items stay `pending_sme` until a scientific reviewer or administrator records an audited decision; skip ≠ pass for E2E without credentials.
- Citation rematch requires PMID + DOI + passage locator in one audited write; rematch resets approval (source edit → unreviewed) and never auto-approves Gate C.
- Gold-set scores and expected labels stay null until an SME fills them; evaluation runners report honest denominators (labelled vs pending) and never invent performance metrics.
- Reuse Neon evidence curation, scientific review queue, and Discovery gap reviews; additive migrations only for SME gold labels / work-item audit — no second knowledge graph.
